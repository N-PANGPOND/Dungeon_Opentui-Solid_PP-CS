# สรุปสถาปัตยกรรมและรายละเอียดการแก้ไขระบบ (Event Splash Screen & Shop System)

เอกสารสรุปรายละเอียดการแก้ไขและสร้างไฟล์ทั้งหมดในโปรเจกต์ ว่าแต่ละไฟล์ถูกแก้ไข/สร้างจุดไหน และทำไปด้วยเหตุผลใด เพื่อให้เข้าใจโครงสร้างระบบได้อย่างครบถ้วน

---

## 📑 สรุปการแก้ไขตามรายไฟล์

### 1. `Source-code/Type-Enum/type.ts`
* **สิ่งที่แก้ไข:**
  * เพิ่ม `"EVENT"` และ `"SHOP"` เข้าไปใน type `gameScreen`
* **เหตุผลที่แก้:**
  * เพื่อให้ TypeScript และระบบ State Management รู้จักสถานะหน้าจอใหม่ของเกม (`"EVENT"` และ `"SHOP"`) ทำให้ไฟล์อื่นๆ สามารถตรวจสอบและสลับโหมดหน้าจอได้โดยไม่เกิด Type Error

---

### 2. `Source-code/Event/Shop.ts`
* **สิ่งที่แก้ไข:**
  * เพิ่มฟังก์ชัน `getItems()` สำหรับดึงรายการสินค้าทั้งหมดในร้าน
  * พัฒนาฟังก์ชัน `buyItem(itemIndex, player)`: ตรวจสอบสินค้า, เช็คจำนวนเงิน (Coin), ตรวจสอบช่องกระเป๋าว่าเต็มหรือไม่ (จำกัด 8 ช่อง), หักเหรียญ และเพิ่มไอเทมเข้าตัวผู้เล่น
  * พัฒนาฟังก์ชัน `sellItem(slotIndex, player)`: ดึงไอเทมจากกระเป๋าผู้เล่นตามช่องที่เลือก, ลบไอเทมออกจากกระเป๋า, คำนวณเงินคืน 80% ของราคาเดิม และเพิ่มเงินให้ผู้เล่น
  * พัฒนาฟังก์ชัน `Leave()`: จัดการออกจากร้านค้า
* **เหตุผลที่แก้:**
  * เพื่อให้ระบบร้านค้าทำงานได้ครบถ้วนตามข้อกำหนด **FR-04** (Buy, Sell, Leave) อย่างสมบูรณ์ เชื่อมโยงเงินและกระเป๋าของผู้เล่นจริง

---

### 3. `Source-code/Game/State.ts`
* **สิ่งที่แก้ไข:**
  * โหลดข้อมูล Pixel Art จาก `event.json` มารอไว้ตั้งแต่เริ่มต้น
  * เพิ่มตัวแปร `pendingEvent` เพื่อเก็บข้อมูลภาพ Pixel Art ของเหตุการณ์ที่เพิ่งสุ่มเจอ
  * เพิ่มตัวแปร `currentShop` และฟังก์ชัน `getShop()`
  * ปรับปรุงฟังก์ชัน `eventShop()`: สร้าง instance ร้านค้า, เซ็ตข้อมูล Pixel Art ลงใน `pendingEvent`, และเปลี่ยนสถานะเกมเป็น `gameScreen = "SHOP"`
  * เพิ่มฟังก์ชัน `buyFromShop(itemIndex)`, `sellToShop(slotIndex)`, และ `leaveShop()` พร้อมส่ง log ข้อความแจ้งเตือนผลการทำรายการ
  * เพิ่มฟังก์ชัน `getPendingEvent()` และ `clearPendingEvent()`
* **เหตุผลที่แก้:**
  * ทำหน้าที่เป็นศูนย์กลางของ Game Logic จัดการ state การซื้อขายและการเข้า/ออกจากร้านค้า โดยแยก logic ออกจากฝั่ง UI ชัดเจน

---

### 4. `Source-code/Tui/uiTypes.ts`
* **สิ่งที่แก้ไข:**
  * เพิ่ม `"EVENT"` และ `"SHOP"` ใน `UIScreen`
  * สร้าง Interface `EventScreenUIProps` (สำหรับส่งข้อมูล Pixel Art ให้ Splash Screen)
  * สร้าง Interface `ShopItemUI` และ `ShopUIProps` (สำหรับส่งรายการสินค้า, ราคา, คำอธิบาย และเหรียญของผู้เล่น)
* **เหตุผลที่แก้:**
  * กำหนดโครงสร้างข้อมูล (Type Definition) ให้ component ฝั่งหน้าจอ TUI ใช้งานร่วมกับ Game Logic ได้อย่างถูกต้องและปลอดภัย

---

### 5. `Source-code/Tui/gameBridge.ts`
* **สิ่งที่แก้ไข:**
  * เพิ่มฟังก์ชัน `getEventScreenProps()` และ `getShopUIProps()`
  * ปรับฟังก์ชัน `resolveScreen(gs: GameState)`: ตรวจสอบ `pendingEvent` ก่อน `SHOP`
* **เหตุผลที่แก้:**
  * ทำหน้าที่เป็น Bridge แปลงข้อมูลจาก GameState ไปเป็น Props สำหรับ UI
  * การตรวจ `pendingEvent` ก่อน `SHOP` ทำให้เมื่อผู้เล่นเดินเจอร้านค้า จะแสดงหน้าจอ **Pixel Art Splash Screen** ก่อน 3 วินาที แล้วจึงเปลี่ยนเข้าสู่หน้าจอซื้อขายอัตโนมัติ

---

### 6. `Source-code/Tui/components/ShopView.tsx` *(สร้างขึ้นใหม่)*
* **สิ่งที่สร้าง:**
  * คอมโพเนนต์หน้าต่างร้านค้าขนาดใหญ่ แสดงแทนที่ช่องแผนที่ (MAP box)
  * แสดงข้อความต้อนรับและจำนวนเงินคงเหลือของผู้เล่น (`💰 Coins`)
  * **โหมดซื้อ (`[B]` Buy Mode):** แสดงรายการสินค้า 1-5, ราคา, และคำอธิบาย (แสดงราคาเป็นสีส้ม/เขียวหากซื้อได้ หรือสีแดงหากเงินไม่พอ)
  * **โหมดขาย (`[S]` Sell Mode):** แสดงรายการไอเทมในกระเป๋า 1-8 พร้อมราคาขายคืน (80%)
* **เหตุผลที่สร้าง:**
  * ออกแบบ UI สำหรับการซื้อ-ขายในร้านค้าให้สวยงาม ชัดเจน และใช้งานง่ายใน Terminal

---

### 7. `Source-code/Tui/components/ActionPanel.tsx`
* **สิ่งที่แก้ไข:**
  * เพิ่มการแสดงผลปุ่มควบคุมเมื่ออยู่ในหน้าจอ `"SHOP"`:
    - `1-5      Buy Item`
    - `S        Sell Mode (1-8)`
    - `B        Buy Mode`
    - `L / ESC  Leave Shop`
* **เหตุผลที่แก้:**
  * แสดงปุ่มคีย์ลัดที่มุมขวาล่างให้สอดคล้องกับสถานะหน้าจอร้านค้า เพื่อความสะดวกของผู้เล่น

---

### 8. `Source-code/Tui/components/Header.tsx`
* **สิ่งที่แก้ไข:**
  * เพิ่มฟังก์ชัน `shopHints()`: แสดงคำแนะนำปุ่มกด `1-5: Buy    S: Sell Mode    B: Buy Mode    L/ESC: Leave Shop` บนแถบหัวข้อด้านบนสุดเมื่ออยู่ในหน้าจอร้านค้า
  * กู้คืนฟังก์ชัน `combatHints()` สำหรับการต่อสู้
* **เหตุผลที่แก้:**
  * ให้คำแนะนำปุ่มกดบน Header สอดคล้องกับทุกหน้าจอ (Dungeon, Combat, Shop)

---

### 9. `Source-code/Tui/components/EventSplashScreen.tsx` & `CombatView.tsx`
* **สิ่งที่แก้ไข:**
  * ปรับขนาดการแสดงผลให้อยู่ในกรอบแผนที่ (94 × 29 ช่อง)
  * แปลงข้อมูลเมทริกซ์ 0 และ 1 จาก `event.json` ให้กลายเป็นภาพ Pixel Art บน Console
  * `EventSplashScreen`: แสดงภาพเหตุการณ์ (Trap, Treasure, Potion, Shop) พร้อมตัวเลขนับถอยหลัง
* **เหตุผลที่แก้:**
  * ให้การแสดงภาพกราฟิกคงเลย์เอาต์เดิมของจอไว้ ไม่บดบังแถบเลือด, กระเป๋า และข้อความ Log ด้านล่าง

---

### 10. `Source-code/Tui/tui.tsx`
* **สิ่งที่แก้ไข:**
  * เพิ่ม Signal `shop` และ `shopMode` (`"buy"` | `"sell"`)
  * เพิ่มการสลับแสดงผล `<ShopView>` ใน `<Switch>` เมื่อหน้าจอเป็น `"SHOP"`
  * เพิ่มการรับปุ่มคีย์บอร์ดในหน้าจอร้านค้า (`1-5` ซื้อ, `1-8` ขาย, `S` สลับโหมดขาย, `B` สลับโหมดซื้อ, `L`/`ESC` ออกจากร้าน)
  * เพิ่มระบบกดปุ่ม `Space` / `Enter` ในหน้า Splash Screen เพื่อข้ามและเข้าสู่ร้านค้าได้ทันที
* **เหตุผลที่แก้:**
  * รวม Component, State และ Event Listener ทั้งหมดเข้าด้วยกันใน Application Loop ของ OpenTUI Solid

## 🔄 สรุปขั้นตอนการทำงาน (User Flow)

1. **เดินสำรวจดันเจี้ยน:**
   - ใช้ปุ่ม `W/A/S/D` หรือ `Arrow Keys` เดินสำรวจ
2. **สุ่มเจอ Event ร้านค้า (`● SHOP`):**
   - **Step 1:** แสดงภาพ Pixel Art ร้านค้าสีฟ้า (Cyan) เต็มช่องแมพ พร้อมเวลานับถอยหลัง 3 วินาที (หรือกด `Space`/`Enter` เพื่อข้าม)
   - **Step 2:** เมื่อหมดเวลา หน้าจอจะเปลี่ยนเป็น **Merchant Shop Panel**
3. **การซื้อ-ขายในร้านค้า:**
   - **ซื้อสินค้า:** อยู่ใน Buy Mode แล้วกดเลข `1 - 5` เพื่อซื้อไอเทม (เงินจะลด และไอเทมจะเพิ่มในกระเป๋า)
   - **ขายสินค้า:** กด `S` เพื่อเข้า Sell Mode แล้วกดเลข `1 - 8` ตามช่องไอเทมที่ต้องการขาย (ไอเทมจะถูกลบ และได้รับเงิน 80%)
   - **ออกจากร้านค้า:** กด `L` หรือ `ESC` หน้าจอจะกลับสู่แผนที่ดันเจี้ยนปกติ
